## [표 1] 데이터 세트 개요

수집된 교보문고 IT 카테고리 1~1,000위 베스트셀러 데이터 정보입니다.

| 구분 | 상세 내용 | 비고 |
|---|---|---|
| **수집 대상** | 교보문고 온라인 베스트셀러 | 컴퓨터/IT 카테고리 한정 |
| **수집 규모** | 총 1,000건 (1위 ~ 1,000위) | 결측치 및 중복 데이터 없음 |
| **수치형 변수** | `순위`, `판매가`, `출간일` | 평균, 표준편차 등 통계 분석 용이 |
| **범주형 변수** | `도서명`, `저자`, `출판사`, `ISBN` | 빈도수 및 텍스트 마이닝 활용 |

<br>

<i>목적: 1,000건의 베스트셀러 데이터를 바탕으로 트렌드를 발굴하고<br>효과적인 비즈니스 전략을 수립합니다.</i>
</div>
