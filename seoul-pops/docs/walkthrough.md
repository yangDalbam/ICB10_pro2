# 서울 생활인구 데이터 기본 EDA 대시보드 구축 완료

요청하신 `LOCAL_PEOPLE_DONG_202606_optimized_final.parquet` 파일에 대한 탐색적 데이터 분석(EDA) Streamlit 대시보드 구축을 성공적으로 완료하였습니다.

## 📁 디렉토리 구조 설정
워크스페이스 규칙(`file-folders.md`)에 따라 기존 `seoul-pops` 프로젝트 폴더 하위에 다음 구조를 구성하였습니다.
```
seoul-pops/
├── images/     # 시각화 이미지 저장소 (자동 생성됨)
├── docs/       # 문서
├── src/        # 소스 코드 (app.py, utils.py)
├── report/     # 분석 리포트 저장소 (eda_report.md)
└── data/       # (기존) 데이터 폴더
```

## 🛠 주요 구현 내용
규칙(`eda-basic.md`)에 따라 아래의 요구사항을 모두 충족하도록 대시보드를 구성했습니다.

1. **데이터 개요 탭 (`Data Overview`)**
   - 상/하위 5개 행 출력 및 `info()` 등 기본 정보 제공
   - 결측치 및 중복 데이터(약 850만 건 대상) 확인
   - 수치형, 범주형 변수를 모두 고려한 1000자 이상의 **자동 생성 분석 보고서** 기능

2. **다차원 데이터 시각화 탭 (15개 이상)**
   - `seaborn` 스타일을 배제하고 `matplotlib` 기본 스타일에 `koreanize-matplotlib`를 적용하여 명확한 한글 시각화 제공
   - 단일변량 (성별/연령 빈도), 이변량 (시간/성별 평균), 다변량 (시간 x 연령대 피벗 등)을 결합한 15개의 차트 구현
   - 각 시각화 하단에 **관련 통계표** 및 **50자 이상의 해석** 제공
   - 차트 생성 시 `seoul-pops/images` 디렉토리에 고해상도(`.png`) 이미지로 즉시 자동 저장

3. **분석 리포트 탭 (`Report`)**
   - 버튼 클릭 한 번으로 생성된 모든 시각화 결과(상대 경로 기반)와 통계표, 해석 내용이 담긴 하나의 마크다운 파일(`seoul-pops/report/eda_report.md`)을 자동으로 생성합니다.

## 📊 Plotly 기반 대화형 차트 (Interactive Charts) 전면 교체 (최근 업데이트)
사용자 요청에 따라 기존의 정적 이미지 형태인 Matplotlib 시각화 자료를 모두 걷어내고, 마우스 오버, 줌인, 영역 선택 등이 가능한 **Plotly 기반 대화형 차트**로 전면 교체하였습니다.

- **차원 높은 데이터 탐색**: 15개의 모든 차트(막대, 선형, 파이, 박스플롯, 히트맵 등)에 마우스를 올리면 정확한 수치와 항목을 툴팁으로 바로 확인할 수 있습니다.
- **초고속 SQLite DB 기반 아키텍처**: 850만 건의 방대한 Parquet 원본 데이터를 미리 조합하여 약 28만 건으로 최소 집계(Aggregation)한 후 `sqlite3` DB에 저장했습니다. 이로 인해 대시보드 로딩과 다중 필터링 속도가 최대 10배 이상 비약적으로 향상되었습니다. 지도 시각화에 필요한 쿼리 역시 시간대별/구별/동별 전용 테이블로 분리해 성능을 극대화했습니다.
- **Plotly 인터랙티브 차트 (15개 이상)**: 성별, 연령대, 시간대별 생활인구 동향을 다변량으로 분석하여 직관적인 Plotly 차트로 제공합니다.
- **Folium 기반 지도 시각화**: 서울시 행정동/구별 생활인구 밀집도를 코로플리스 맵(Choropleth Map)으로 렌더링하며 필터링과 실시간으로 연동됩니다. (지역별 인구수 마우스오버 툴팁 포함)
- **1000자 분석 리포트 자동 생성**: 시각화된 차트와 통계를 바탕으로 자동으로 마크다운(.md) 보고서를 추출하고 저장합니다. Plotly 차트 또한 백그라운드에서 기존과 동일하게 `.png` 포맷으로 `images/` 폴더에 자동 저장되도록 리팩토링했습니다. 이로 인해 리포트 생성 기능이 완벽히 호환됩니다.

## 🔄 동적 필터링(Dynamic Dashboard) 기능
좌측 사이드바(Sidebar)를 활용해 원하는 데이터를 조건에 맞게 필터링할 수 있습니다.

## 🚀 실행 방법
터미널(또는 명령 프롬프트)에서 아래 명령어를 실행하여 대시보드를 띄울 수 있습니다.
```bash
uv run streamlit run seoul-pops/src/app.py
```

> [!TIP]
> 데이터가 약 850만 행에 달하므로, Streamlit의 `@st.cache_data`를 활용하여 최초 로드 시에만 연산을 수행하도록 최적화했습니다. 초기 화면이 렌더링될 때만 다소 시간이 소요될 수 있습니다.

> [!NOTE]
> 코드 작성 규칙인 **파이썬 모듈 Docstring 필구** 요건을 충족하기 위해 `app.py` 및 `utils.py` 최상단에 한국어 설명 주석을 모두 포함해 두었습니다.
